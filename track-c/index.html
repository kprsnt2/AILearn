TRACK C · POST-TRAINING & REASONING

Post-training & Reasoning - 25 lessons

How behaviour is manufactured: SFT, preferences, RL, and reasoning.

A pretrained model is a predictor. Everything you actually interact with is a product of post-training. This track covers how behaviour is manufactured: supervised fine-tuning, preference learning, RL with verifiable rewards, the reasoning-model recipe, and the failure modes that make all of it fragile. Every objective is implemented, not described.

L51 → L75 build: A toy RL post-training loop with a verifiable reward prereq: Track A lessons 03-04 (gradients), and Track B lessons 26-28

Why this track exists

01

You will implement the losses, not cite them

DPO, GRPO and PPO clipped surrogate in numpy, so the equations stop being incantations.

02

Reward hacking becomes a design problem

You already gate promotions. This track generalises the gate into an RL training discipline.

03

Reasoning becomes an engineering budget

Chain-of-thought, test-time compute, and reasoning effort are all the same tradeoff viewed from different angles.

By the end you can

  • Write the DPO and GRPO objectives from memory and explain the group baseline
  • Design a verifiable reward function and then attack it yourself
  • Explain when reasoning distillation beats RL and when it merely imitates
  • Detect reward hacking with a concrete invariant rather than a vibe

Prerequisites

Track A lessons 03-04 (gradients), and Track B lessons 26-28. Probability helps.

The artifact: A toy RL post-training loop with a verifiable reward, a reward-hacking test suite, and a measured before/after.

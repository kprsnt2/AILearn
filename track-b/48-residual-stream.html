L48 · The Residual Stream as Shared Memory (Mechanistic View)

Every attention block and MLP reads a width-4096 vector and adds back to it. Nothing else is shared between layers. Once you see the model as 61 modules reading and writing one communication channel, superposition, prompt sensitivity and surgical fine-tuning stop being mysterious.

~28 min difficulty ●●●●● build: logit lens on a tiny model
residual stream read / write subspaces superposition logit lens virtual weights feature directions layer-by-layer composition

1 · Why it exists #

You have shipped models and been surprised by them: a one-word prompt change flips a classification, a fine-tune on a narrow task degrades an unrelated one, a checkpoint that scores well on evals writes a subtly different code style. The residual stream is the structural fact that explains most of this.

The failure it addresses is interpretability of a stack. In a plain feed-forward network, layer 3's output is transformed by layer 4, so information is repeatedly rewritten and there is no stable place to look. Residual connections change that: each block computes an update Δ and adds it to a vector that persists from the embedding to the output. Nothing is overwritten. Every layer can, in principle, read anything an earlier layer wrote.

That gives you the single view that makes modern interpretability tractable: the transformer as a set of independent modules — attention heads and MLPs — all reading from and writing to one shared memory of width dmodel = 4096 per token. The residual stream is 4096 × 4 bytes = 16,384 bytes per token in fp32, and it is the only communication channel in the model.

Layers do not pass hidden states to each other; they take turns using a shared bus. Everything about prompts, fine-tuning and reliability follows from the properties of that bus — especially that it is far too narrow for the number of features the model needs.

2 · The mental model #

Analogy (labelled): a whiteboard shared by a team, where each specialist walks up, reads whatever they need, and erases nothing — they add. The board is not subdivided into sections; the first write and the last write exist simultaneously, in the same space.

What the analogy gets right

Additive composition, no overwriting, concurrent writers. It also gets the key constraint right: the board has finite area, so writers must share space.

Where it breaks

A whiteboard is unambiguous to a human reader because handwriting and position differ. There is no reader — only learned linear maps. So two features written into overlapping directions interfere numerically unless the model's read vectors are close enough to orthogonal. That interference is the real cost, and it is what superposition formalises.

The one-line architecture

x0 = Embed(token)  ;  xl = xl−1 + Attnl(xl−1) + MLPl(·)  ;  logits = WU xL Two additions per layer. Attn reads x, computes an update, adds it back; MLP does the same. The output projection WU reads the final stream. Every module's "input" and "output" live in the same 4096-dim space, which is what makes the stream a bus rather than a pipeline.

3 · The mechanism #

Read and write subspaces

An attention head is not a monolithic operator on the stream. It is a pair of linear maps:

  • A read matrix WQWin (plus WK, WV) that projects the stream onto a low-dimensional subspace — what this head is looking for.
  • A write matrix WoutWV that projects the head's output back into the stream — what this head adds.

The head's actual contribution is the virtual weight WoutWVWQWin, a rank-≤dhead matrix on the stream. With dhead = 128 and dmodel = 4096, each head can only read and write a 128-dimensional slice of a 4096-dimensional bus — 3.1% of the space. The model's expressiveness comes from composing many such low-rank read/write pairs.

Superposition: why 4096 dimensions is not enough

A model may need to represent thousands of distinct features. If each needed its own dimension, 4096 dimensions would cap the feature count — and empirical work on sparse coding of activations finds far more features than dimensions. The resolution is that features are represented as directions, not axes, and directions can be nearly-orthogonal in high dimensions.

interference ≈ |ci cj|  (fθi · fθj) ci = feature activation magnitude, θ = direction. In n dimensions there are exponent-ially many directions with small mutual inner product, so more than n features fit with small accuracy loss. Superposition is the deliberate trade of exactness for count — and the cost shows up as interference errors on unusual inputs.

In 4096 dimensions, random pairs of unit vectors have expected absolute inner product near 1/√4096 = 0.0156; the sampled mean over many pairs is ≈0.0125 (the root-mean-square is 0.0156 — the half-normal mean is smaller than its scale parameter), i.e. about 1.25% interference. That small number is why hundreds of features can share the space — and why precision quantisation (L40) hurts more than the byte count suggests: it adds noise to a signal that is deliberately riding close to others.

Logit lens: reading the stream before the end

Because WU is just a linear read of the stream, you can apply it early. For each layer l, compute softmax(WUxl) and see what the model would predict if it stopped there. This is the logit lens, and it is the cheapest useful interpretability tool available.

What it reveals state as of 2026-10: predictions converge gradually. In a well-trained model the top-1 token often becomes correct by the middle layers and only grows in confidence. When it does not — when the model is confident-and-wrong at layer 20 and corrects itself at layer 30 — you are looking at a competing feature being overridden, which is a concrete bug (or safety) signal rather than a vague “the model got it wrong.”

Why surgical fine-tuning works

If modules are readers and writers on a shared bus, then training on a narrow task primarily moves the read/write directions of the modules that implement that task. That is why LoRA on attention projections can steer style and format without changing underlying knowledge: it edits a low-rank subspace of the bus, and the rest of the bus is untouched numerically. The failure mode is that the edited subspace overlaps features you did not intend to change, which is why narrow fine-tunes produce unexpected side-effects.

The audit artifact is a layer-wise prediction trace: for a fixed input, the top-1 token and its probability at every layer, plus the residual norm per layer. Cheap to compute, easy to diff between checkpoints, and it catches regressions that aggregate benchmarks average away. Log it for your golden set at every model change.

4 · Your hands #

Experiment 1 — interference in high dimensions, measured

Before believing the superposition story, verify the geometry it rests on. This is the whole argument in fifteen lines.

import numpy as np rng = np.random.default_rng(48) def interference(n_dim, n_features): F = rng.normal(0, 1, (n_features, n_dim)) F /= np.linalg.norm(F, axis=1, keepdims=True) G = np.abs(F @ F.T); np.fill_diagonal(G, 0) return G.max(), G.mean() for d in (64, 1024, 4096): for nf in (100, 1000, 4000): mx, mean = interference(d, nf) print(f"d={d:5d} features={nf:5d}: mean |cos|={mean:.4f} max |cos|={mx:.4f}")

Measured mean |cos|: at d = 64 it is 0.1001 (0.125 is 1/√64 — the sampled mean is lower); at d = 1024, 0.0244–0.0249; at d = 4096, 0.0124–0.0125. Crucially the mean is flat in the number of features (100, 1,000 or 4,000 all give the same mean), while the maximum rises (0.0651 → 0.0705 → 0.0907 at d = 4096) as packing tightens. That is exactly the superposition trade: many features fit at small average interference, and the model pays in a few near-collisions whose severity grows with packing. Falsification: if mean interference scales with feature count at fixed d, the vectors are not centred and you are measuring a mean offset, not interference.

Experiment 2 — a logit lens on a toy residual stack

Reproduce the logit-lens mechanic with no transformer: a residual stack of random-but-decaying updates and a decoder matrix. Watch the prediction converge layer by layer, and watch what a mid-layer override looks like.

import numpy as np rng = np.random.default_rng(480) d, V, L = 64, 10, 12 Wu = rng.normal(0, 1, (V, d)) / np.sqrt(d) target = 7 x = rng.normal(0, 0.5, d) def top1(x): z = Wu @ x; p = np.exp(z - z.max()); p /= p.sum() return int(p.argmax()), float(p.max()) for layer in range(L): # each "layer" adds a small update aligned with the target's read direction delta = rng.normal(0, 0.35, d) + 0.5 * Wu[target] x = x + delta print(f"layer {layer+1:2d}: top1={top1(x)[0]} p={top1(x)[1]:.3f} |x|={np.linalg.norm(x):.2f}")

Measured: top-1 is a different token (3) for layers 1–4 with probability rising 0.196 → 0.397, then flips to the target (7) at layer 5 and rises monotonically to 0.806 by layer 12. The residual norm grows linearly (5.51 → 11.04) — both signatures to look for in a real logit lens. Note the early layers are genuinely confident about the wrong answer: that is a mid-stack override in miniature, and in a real model it is where prompt sensitivity comes from. Note the norm growth: residual norms typically increase with depth, which is why LayerNorm/RMSNorm placement (L05) matters.

Experiment 3 — why two prompt variants can diverge

Model the stream as a sum of feature contributions and show that a small change to an early write has a larger downstream effect than the same change late — because every later module reads it.

python -c " import numpy as np rng=np.random.default_rng(4) d=256; d_read=16 reads=[rng.normal(0,1,d) for _ in range(8)] # 8 downstream modules' read directions reads=[r/np.linalg.norm(r) for r in reads] def effect(edit_layer, delta): contrib=np.zeros(3) for i,r in enumerate(reads): if i>=edit_layer: contrib[0]+=abs(r@delta) return contrib[0]/len(reads) base=rng.normal(0,1,d) for l in (0,2,4,6): dl=np.zeros(d); dl[:]=rng.normal(0,0.05,d) print(f'edit at module {l}: mean downstream |projection| = {effect(l,dl):.4f}') "

An edit at module 0 is read by all 8 downstream modules; an edit at module 6 by only 2. The mean downstream projection therefore falls with the edit's depth. That is why early-token and early-layer perturbations (a changed system prompt at position 0, a different first word) can matter more than a change buried in a long context — and why prompt position, not prompt length, drives variance.

5 · Failure modes #

  • Superposition interference. Symptom: the model is reliable on frequent feature combinations and flaky on rare ones, with errors that look like conflating two related concepts. That is characteristic of near-colliding directions.
  • Fine-tune collateral damage. Symptom: a narrow LoRA improves its target task and degrades an unrelated capability by a few points. The edited subspace overlaps a feature it should not have touched; reduce rank, or restrict which modules are adapted.
  • Prompt-position sensitivity. Symptom: two prompts with identical content in different order produce materially different outputs. Early content is read by more modules; put invariant instructions first (which also happens to maximise prefix-cache hits, L45).
  • Logit lens used as ground truth. Symptom: you conclude “the model knows X at layer 12” and it does not, because WU is only trained to read the final stream; early layers may use a different basis. Treat logit-lens outputs as a diagnostic, not a readout of belief.
  • Residual norm blowup. Symptom: layer norms grow with depth in the trace, final outputs are over-confident, and long sequences degrade more than short ones. Often a sign of a stability problem (L12) rather than an interpretability finding.

7 · Self-check #

Q1. A head has dhead = 128 on a dmodel = 4096 stream. What fraction of the stream's space can it read and write, and what is the rank of its virtual weight?

Reveal answer

128/4096 = 3.125% of the dimensions. Its virtual weight WoutWVWQWin has rank at most 128 — it is a rank-≤128 linear map on a 4096-dimensional space. That is why heads are compositional: each is a small, interpretable projection, and capability comes from many of them layered on the same bus.

Q2. Expected |cosine| between two random directions in 64, 1024, and 4096 dimensions. What does that imply for how many features fit at ~1% interference?

Reveal answer

1/√d: 0.125, 0.031, 0.0156. So at 4096 dimensions the typical pair has 1.56% interference before accounting for learned (non-random) directions, which is why thousands of features can share the space. At 64 dimensions a typical pair already interferes 12.5% by the 1/√d scale (0.100 measured) — an order of magnitude worse than at 4096, which is why small models are markedly more prone to conflating concepts.

Q3. Diagnostic: the logit lens shows the correct answer with high probability at layer 20, an incorrect one at layer 28, and the correct one again at layer 40. What does this pattern indicate, and what would you do about it?

Reveal answer

A mid-stack override: some feature written between layers 20 and 28 is suppressing the correct prediction, and a later module repairs it. Practically it means the output is fragile — inputs that disable the later correction will produce the wrong answer confidently. Investigate by diffing the stream at the override layers, and test inputs that sit near that boundary; expect prompt sensitivity on exactly those.

Q4. Why might 4-bit weight quantisation degrade quality more than the 4×-fewer-bits suggests, in residual-stream terms?

Reveal answer

Because features are already packed at small mutual interference (order 1.6% for random pairs, and learned directions can be closer). Quantisation adds noise to every read and write matrix, so it raises interference between features that the model deliberately kept close — a small perturbation matters more when the signal margin is small. This is why outlier-aware methods (AWQ, GPTQ, L40) and keeping first/last layers at higher precision recover most of the loss.

Q5. Two fine-tuning plans: (A) LoRA rank 8 on the attention output projections, (B) full fine-tune of all layers, both on a narrow formatting task. Predict the side-effect profiles and why they differ.

Reveal answer

A edits an 8-dimensional subspace per adapted matrix — it can change the formatting behaviour while leaving most of the stream untouched, so collateral damage is small but the task might be under-fit if it needs more capacity. B can move every read/write direction, so it fits the task fully and also risks overwriting features unrelated to the task (the classic forgetting failure, L73) because there is nothing constraining the edit to the intended subspace.

TRACK D · AGENTS, RAG, EVALS, PRODUCTION

Agents, RAG, Evals, Production - 25 lessons

Where the money and the risk live. Systems that run unattended and can be audited.

You already ship agents. This track is deliberately written one level below what you do: the measurement, the invariant, the failure math, the economic model. It treats every agent system as a control system with a budget and an audit trail, and it ends with the one artifact almost nobody produces: a run whose record proves it was correct.

L76 → L10 build: An audited autonomous agent: verifiable evidence bundle prereq: Track C lessons 60-63 for the reasoning/verifier half

Why this track exists

01

Your existing systems get a measurement layer

JobAgents, BugAgents and AgentSwarm become instruments, not just deployments.

02

Evals stop being a demo

Statistical power, confidence intervals, pass@k vs pass^k, and judge calibration that survives review.

03

The audit moat becomes a product

The RAKE harness and the production checklist are the deliverables an enterprise would actually buy.

By the end you can

  • Design an eval with adequate statistical power and state the CI on your result
  • Build an evidence bundle a stranger can recompute without asking you anything
  • State your blast radius in one sentence and defend each of the three controls
  • Run the FABLE auditability rubric on your own systems and publish the honest score

Prerequisites

Track C lessons 60-63 for the reasoning/verifier half. Everything else assumes you build agents already.

The artifact: An audited autonomous agent: verifiable evidence bundle, independent oracle, promotion gates, cost attribution, and a run you can hand to a stranger.

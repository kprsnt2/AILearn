Three ways through this

The default order is bottom-up because that is how it was built — but it is not how you should read it. Read bottom-up if you want to build a model. Read top-down if you need to defend a system this quarter. Read the paper-first route if you want to contribute.

PART TWO · THE DISCOVERY TRACK

SKILLA — a proposed route toward autonomous discovery

Your agents already run unattended, keep tamper-evident ledgers, and gate their own promotions. What they cannot yet do is decide what is worth doing, and prove it after the fact in a way a stranger would accept. SKILLA is a design for closing both gaps: a living skill library that agents must extend or falsify every cycle, plus audit-certified autonomy where the agent's authority is a function of its measured track record.

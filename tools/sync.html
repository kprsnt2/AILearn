SYNC · STUDY ANYWHERE

One code. Laptop, phone, tablet.

Lesson progress, flashcard scheduling and your calibration score follow you. Create a code here once, then type it on every other device. No account, no login screen, no email.

Set up

1

Create a sync code

Click to generate. Write it down somewhere you will find it — it is the only key to this data.

Treat it like a password. Anyone holding this code can read and overwrite your study progress. The data is only lesson numbers, flashcard intervals and a score — nothing personal — but someone with the full code can erase your streak.
2

Use it on another device

On your phone or a second laptop, open this page and paste the same code, then pull.

3

Keep it current

Sync happens automatically when a page loads (at most once a minute). To force it, use these.

Merging is per-record and never destructive: a lesson marked done stays done, and the flashcard record with more reviews wins. Studying offline on your phone will not erase progress made on your laptop.

4

Disconnect

Stops syncing on this device. Your local progress stays exactly as it is.

How it works

The site is static, so there is no server of its own. This stores one small JSON document in a public key-value bucket, addressed by the first part of your code, and writes are gated by the second part.

If the endpoint is unreachable — offline, or the service is down — everything keeps working locally and sync simply retries later. You are never blocked.

Prefer to self-host? Point AILearnSync's remote adapter at any JSON bucket you control (Cloudflare KV, Vercel KV, Supabase). The merge logic does not change.

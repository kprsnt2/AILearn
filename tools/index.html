Arithmetic you can feel.

Reading about KV-cache growth does not stick. Watching the byte count change when you move from MHA to GQA to MLA does. Every tool here is built to make one number undeniable — the same reason you ran a six-way CLI benchmark instead of trusting a leaderboard.

How to use these honestly: a tool you drive for ten minutes is not understanding. The rule is the same as for reading: use a tool only when you will implement or measure something from it within two weeks. The flashcards are the exception — recall maintenance is the one thing that should be habitual.
